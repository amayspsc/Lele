# lelepakabi

Website katalog bibit lele dengan storefront publik dan dashboard admin untuk memperbarui harga serta ketersediaan ukuran bibit.

## Menjalankan

```bash
npm install
npm run dev
```

## Dashboard admin

Klik **Admin** pada header atau **Area admin** di footer. Untuk demo, gunakan:

- Email: `admin@lelepakabi.id`
- Password: `lelepakabi`

Perubahan katalog disimpan di `localStorage` browser dan langsung tercermin di halaman publik setelah disimpan.
